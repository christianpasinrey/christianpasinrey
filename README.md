### 🧭 About me

- 🏗️ I design and build web applications **end-to-end**: architecture, backend, frontend, deployment and maintenance.
- 🏢 **Multi-tenant SaaS** with database-per-tenant isolation, custom auth guards and GDPR-grade handling of health data (encryption at rest + searchable hashes).
- 🏥 Real-world experience in **healthcare apps** (clinical records, traceability, invoicing) and **travel apps** (bookings, itineraries, tour operations).
- 📦 **Open source package author** for the Laravel ecosystem — polymorphic addresses, payment gateways, PDF rendering, page builders.
- 🔌 Production integrations with **Microsoft Graph** (calendar, mail, SharePoint) and custom **MCP servers** for AI-assisted workflows.
- 🎮 Real-time **WebGL / Three.js** work: physics simulation, procedural audio and interactive 3D as a way to keep the fundamentals sharp.
- ⚡ Focused on maintainable code, fast UX and automation that gives hours back to the team.
- 📬 Want to talk? **contacto@christianpasinrey.es**

### 🔭 What I'm working on right now

**Open source packages**

| Package | What it does |
| --- | --- |
| [`laravel-addressable`](https://github.com/christianpasinrey/laravel-addressable) | Polymorphic postal addresses for Eloquent models — purpose roles, local-first geo (GeoNames) and opt-in, cost-aware Google enrichment. |
| [`laravel-cecabank`](https://github.com/christianpasinrey/laravel-cecabank) | Frontend-agnostic Cecabank card gateway: signature engine, polymorphic payment transactions, events and webhook routes. |
| [`pliego`](https://github.com/christianpasinrey/pliego) | HTML/CSS → PDF engine written in pure PHP: compiled CSS, streaming page-by-page rendering and a kernel + plugins architecture. |
| [`vault`](https://github.com/christianpasinrey/vault) | Self-hostable, end-to-end encrypted password vault built with Laravel. |

**Developer tooling & AI workflows**

| Project | What it does |
| --- | --- |
| [`heyclaude`](https://github.com/christianpasinrey/heyclaude) | Voice control for Claude Code on Windows — TTS streaming, push-to-talk STT and wake word, multi-session, 100% local. |
| [`refactoring.guru-skill`](https://github.com/christianpasinrey/refactoring.guru-skill) | An agent skill that forces a deliberate design decision before code is written: 8 pattern catalogues, 66 refactoring techniques, 22 code smells. |
| [`deck`](https://github.com/christianpasinrey/deck) | Native Linux dev environment manager (PHP, Node, databases, `.test` domains) — a Laragon/Herd alternative for Ubuntu. |
| [`bulk-image-generation-skill`](https://github.com/christianpasinrey/bulk-image-generation-skill) | Orchestrated bulk AI image generation with a live dashboard and seed recovery. |

**Real-time WebGL experiments**

| Project | What it is |
| --- | --- |
| [`drift`](https://github.com/christianpasinrey/drift) | A real-time open ocean: physically-simulated Gerstner swells, a sailboat that rides the waves, day-night sky, foam and procedural sea sound. |
| [`human-blood-system`](https://github.com/christianpasinrey/human-blood-system) | **HÆMA** — a WebGL atlas of the human circulatory system: beating heart, blood-cell flow, clickable organs and ECG vitals. |
| [`coreburst`](https://github.com/christianpasinrey/coreburst) | Orbital 3D bubble shooter built with Three.js + TypeScript. |
| [`el-motivo`](https://github.com/christianpasinrey/el-motivo) | Cinematic storytelling site about the stories behind classical works. |
| [`cronologia-espana`](https://github.com/christianpasinrey/cronologia-espana) | Interactive, neutral timeline of Spanish politics 2004–2026, with cited sources. |

Alongside these, most of my day job is **client work under NDA**: multi-tenant SaaS for healthcare professionals, e-commerce platforms and internal business tools — Laravel + Vue/Livewire, deployed and maintained by me.
